# 小程序页面与 UI 重设计（v2）

> 目标：把网页端 8 个功能页完整搬进微信小程序，按手机竖屏重排信息层级与操作路径；视觉延续 `tech-xhs-image` 的科技风 DNA，不再把桌面表格直接缩成手机表格。

## 1. 网页端功能清单（对齐基线）

| 路由 | 页面 | 核心能力 |
| --- | --- | --- |
| `/overview` | 总览 | 4 个 KPI（最高收益 / 盈利配方 / 行情校准 / 满精力预估）、Top 10 收益条、今天精力怎么花、技艺横评、本服行情就绪度、五行石摘要 |
| `/skills/:id` | 生活技艺 | 8 技艺切换、可做/全部双均值、配方表（搜索/品阶/仅盈利）、材料行情内联改价、新增/编辑配方 |
| `/prices` | 行情 | 1116+ 物品逐项定价、来源状态（实价/商店/示例/缺价）、批量粘贴、跨服价差、CSV 导出 |
| `/stones` | 五行石 | 1–8 级行情、快速/最优合成、5/6 级单颗收益、7/8 级爆率盈亏线、剥七/剥八、公式编辑 |
| `/analysis` | 精力收益分析 | 可做/谨慎/不可做评级、可做中位、可做组合、Top 15、成本×收益散点、各技艺箱线、双制品对比、完整收益表、CSV |

| `/server-trends` | 区服趋势 | 17 服热力图、区服榜、主要变动、物品视角跨服涨跌 |

| 更新 | 更新说明 | `content/updates/miniapp.json` 同步的版本说明 |

## 2. 现状问题

1. **今日 ≠ 总览**：现在「今日」只是按技艺的收益排行，没有 KPI、满精力方案、行情就绪度，和网页端总览差距最大。
2. **分析缺页**：`pages/analysis` 只是三个入口，没有「可做/谨慎/不可做」评级、散点、箱线、双制品对比、完整收益表。
3. **行情被藏在二级页**：网页端最高频的「查价/改价」在小程序里要点进「我的/今日」再进，路径太长。
4. **筛选器全是展开式卡片**：手机上展开后把列表顶走，且触控区域偏小。
5. **缺少统一的页面头部**：有的页用 `TopBar`、有的用 `ServerBar`、有的直接裸奔，返回/区服/行情时间的位置不一致。
6. **表格语义过重**：配方/收益/行情在手机上应改成「两行卡 + 右对齐数字」，而不是横向滚动表格。

## 3. 新信息架构

### 3.1 微信端 5 个 Tab

| Tab | 页面 | 回答的问题 |
| --- | --- | --- |
| 今日 | `pages/overview` | 今天精力怎么花？现在做什么最赚？ |
| 技艺 | `pages/skills` | 某个技艺下有什么可做、成本多少？ |
| 行情 | `pages/prices` | 这个材料本服多少钱？哪里没价？ |
| 五行石 | `pages/stones` | 合到几级最赚？7/8 级爆率线多少？ |
| 我的 | `pages/settings` | 服务器、预算、口径、备份、关于 |

小红书端 4 Tab：今日 / 技艺 / 行情 / 我的（不注册五行石与行情目录分包）。

### 3.2 二级页与入口

```
今日
├─ 精力收益分析（pages/analysis）
│  ├─ 可做 / 谨慎 / 不可做
│  ├─ 满精力组合、双制品对比、完整收益表
│  └─ 五行石分析卡 → 五行石 Tab
├─ 物价走势 / 区服趋势 / 突破升级（三张入口卡）
└─ 行情校准 → 行情 Tab

技艺
├─ 配方详情（pages/recipe）
└─ 收益分析 → pages/analysis（带 skill 参数）

行情
├─ 行情目录（market 分包，仅微信）
├─ 批量录入 / 跨服价差
└─ 物价走势 / 区服趋势

五行石
├─ 五行石公式（pages/stone-formula）
└─ 剥七 / 剥八说明

我的
├─ 服务器与价格、精力与口径、外观
├─ 分析中心（走势 / 区服 / 突破）
├─ 数据备份、数据说明、更新说明
└─ 行情目录（仅微信）
```

## 4. 设计语言

### 4.1 色彩与底

- 底：`#120d2a` + 深蓝→紫→洋红→青的流体径向渐变（与网页科技风/小红书图一致）。
- 玻璃卡：`rgba(255,255,255,.07)`、`1rpx` 白边 `rgba(255,255,255,.16)`、`blur(24rpx)`、内高光。
- 强调：橘 `#FD7B4C` / `#FF9A6B`，只用于选中态、主按钮、标题下划线、序号。
- 语义：涨/正 `#4ADE80`，跌/负 `#FF5C7A`，提示 `#F5B301`，信息 `#7AB8FF`。
- 文字：主白、次 `rgba(255,255,255,.68)`、弱 `rgba(255,255,255,.45)`。

### 4.2 字号（rpx，750 设计宽）

| 角色 | 字号 / 字重 |
| --- | --- |
| 页面大标题 | 58 / 900，行高 1.12 |
| 区块标题 | 34 / 800 |
| 卡片标题 | 30 / 700 |
| 正文 | 26 / 400 |
| 辅助 | 22 / 400 |
| 数字 KPI | 56–64 / 800，tabular |
| 单位/说明 | 20 / 500 |

### 4.3 间距与触控

- 页面左右 24rpx；卡片内 28rpx；卡片间距 20rpx；区块间距 32rpx。
- 最小点击区域 88×88rpx（≈44pt），列表行高 ≥ 104rpx。
- 底部 Tab 安全区 + `env(safe-area-inset-bottom)`；主行动按钮吸底。

### 4.4 组件

| 组件 | 说明 |
| --- | --- |
| `PageHeader` | 区服 pill + 行情时间 + 页面动作；标题由原生导航栏承担，避免重复 |
| `StatGrid` | 2×2 玻璃 KPI 卡；数字大、单位小、脚注一行 |
| `Section` | 标题（左侧 6rpx 橘条）+ 右侧动作 + 内容 |
| `Seg` | 胶囊分段；选中橘底深字 |
| `ChipRow` | 横向滚动筛选 chip；选中橘边 |
| `Sheet` | 底部弹层，承载筛选、批量录入、改价；遮罩 + 圆角 + 安全区 |
| `RankRow` | 名次 / 名称 / 副信息 / 右对齐收益；第一名橘色 |
| `PriceRow` | 物品名 + 来源标签 + 右侧可编辑价格 |
| `Empty` | 图标 + 一句话 + 一个行动按钮 |

### 4.5 动效

- 弹层 220ms 上滑；Tab 切换保留 1px 顶部进度条。
- 数字变化不做滚动动画，避免频繁重算时闪动。
- 列表加载更多用「加载更多 · x/y」按钮，不做无限滚动，避免误触。

## 5. 页面规格

### 5.1 今日（总览）

1. `PageHeader`：今日 + 区服/行情时间。
2. Hero：一句话结论「本服现在最赚的是 X，约 N 金/精力」+ 大数字。
3. KPI 2×2：最高收益、盈利配方（正/负）、行情校准（已校准/总）、满精力预估（金）。
4. `Section 今天精力怎么花`：预算 chips（100/200/500/1000/全部）+ 满精力方案（总收益、用尽精力、前 3 分配）。
5. `Section 现在做什么最赚`：类型分段 + Top 10 横向条形（CSS bar）。
6. `Section 技艺横评`：8 技艺平均收益条形 + 最优产物。
7. `Section 分析`：三张入口（物价走势 / 区服趋势 / 突破升级）+ 精力收益分析大卡。
8. 五行石速答（仅微信）：合到几级最赚 + 7 级爆率线。
9. 行情就绪度：已校准/缺价/更新时间 + 去补价。

### 5.2 技艺

1. `PageHeader`：生活技艺 + 区服 + 「收益分析」入口。
2. 技艺 chip 行（8 个，带类型点）。
3. 4 个统计：配方数、可做配方、可做均值、全部均值。
4. 搜索 + 筛选按钮（品阶/仅盈利/仅可做）→ `Sheet`。
5. 配方列表：名称 + 产物 + 成本/精力 + 右对齐「利润 / 金每精力」+ 状态标签。
6. 本技艺材料行情：可编辑价格，改完即时重算。
7. 吸底「新增配方/采集点」。

### 5.3 行情

1. `PageHeader`：行情 + 区服 + 行情时间。
2. 搜索框（吸顶）+ 筛选（分类 / 类型 / 技艺 / 仅缺价）→ `Sheet`。
3. 进度条：已校准 / 本服报价 / 缺价。
4. 物品列表：名称 + 分类/技艺 + 来源标签 + 右侧改价。
5. 批量录入 `Sheet`（每行「物品名,价格」）+ 跨服价差（Top 5）。
6. 微信：行情目录分包入口。
7. 底部：复制 CSV / 复制 JSON（用于 Excel 或备份）。

### 5.4 五行石

1. `PageHeader` + 结论卡（合到几级最赚、单颗利润、精力）。
2. 模式分段：快速 / 最优 / 精力收益。
3. 1–8 级行情（横向卡片，可展开改价）。
4. 等级收益列表（目标等级 / 成本 / 利润 / 精力收益）。
5. 7/8 级爆率盈亏线 + 剥七/剥八参考。
6. 公式列表 + 新增/编辑入口。

### 5.5 精力收益分析（新）

1. `PageHeader` + 口径分段（市场价 / 取最低）+ 可做筛选（可做/谨慎 / 全部）。
2. 4 个 KPI：最高可做、可做中位、暂不可做、可做组合收益。
3. 可做组合：精力预算、分配列表（Top 5）、用尽/闲置。
4. 收益排行 Top 15（条形 + 中位参考线）。
5. 成本×收益散点：用 CSS 定位气泡（成本 x、精力收益 y、精力=气泡大小），不引入 Canvas。
6. 双制品对比：两个 Picker + 指标行 + 差值。
7. 完整收益表：分页 30 条/页，行点击进配方详情。
8. 评级口径说明（A/B/C 与网页审计的差异）。

### 5.6 我的

1. 服务器卡：当前区服、行情时间、切换、新增/删除。
2. 分析中心：走势 / 区服趋势 / 突破升级 / 行情目录（微信）。
3. 计算设置：精力预算、默认精力、成本口径、交易税。
4. 外观：亮色 / 暗色 / 科技风。
5. 数据：复制备份、导入备份、清空本服价格、恢复示例配方、重置全部。
6. 关于：版本、更新说明、数据来源、免责声明。

### 5.7 二级页统一

- 全部加 `PageHeader` 的紧凑版（返回按钮由原生导航提供）。
- 突破 / 走势 / 区服趋势保留现有功能，仅统一卡片、chip、按钮样式。
- 配方详情：分区（结论 / 材料 / 产物 / 编辑），吸底保存。

## 6. 移动端适配规则

| 网页做法 | 小程序做法 |
| --- | --- |
| 宽表格 | 两行卡 + 右对齐数字；点行看详情 |
| 顶部/侧边筛选栏 | 搜索吸顶 + 筛选 `Sheet` |
| 分页器 | 「加载更多 · x/y」 |
| 悬停 tooltip | 长按/点按说明弹 `showModal` 或行内小字 |
| PNG / CSV 下载 | 复制 CSV/JSON 到剪贴板；图表不导出 |
| Excel 下载 | 我的 → 关于里提供链接复制 |
| 多列图表 | CSS 条形 / 气泡；趋势曲线仅微信 Canvas |
| 键盘输入 | `type='digit'`、保存时校验；改价后 toast 并即时重算 |
