## 4. 需要新增的模块

### N1 · `assets/quote.js`（报价可信度）

- **作用**：`QuoteTrust.get(serverId,itemId)` → `{price, source, level, sample, quoteAt, ageHours, coverageServers, quotePersistence, priceCv}`。
- **依赖**：`data.js` 的 `serverQuoteMeta`、`price-history` 回放。
- **验收**：
  - 无报价 → `level='缺价'`；
  - base → `level='示例价'`；
  - 商店 → `level='商店价'`；
  - 本服报价 + sample>=5 + age<=6h → `level='实价'`；
  - 本服报价但 sample/age 不足 → `level='薄价'`。

### N2 · `assets/access-data.js`（材料获取难度）

- **作用**：`itemAccess[itemId] = {access, sources, vendor, craftable, hardGate, verifiedAt}`。
- **来源**：JX3BOX 物品 API + 人工覆盖 `scripts/item-access-overrides.json`。
- **验收**：地脉玄元/境华/铃兰=硬缺口；蜂王浆/兽皮胶=软约束；炼火石/煤炭/石灰/百染线=商店；熟铁锭/密银锭=可自产。

### N3 · `assets/landability.js`（落地评级）

- **作用**：`grade(recipe, serverId, at)` → `{grade, feasible, paperPerEnergy, strictPerEnergy, blockedBy, thinReasons, selfCraft, requiredSkills}`。
- **依赖**：N1/N2 + `profit.js` 的 `evaluate`。
- **验收**：
  - 严格视图：A27/B21/C106；
  - 玄元星平衫 C（地脉 + 成品）；
  - 巴山 A；苍生磨石 B；定魂丹砂 C；
  - 自产默认进 B，不混 A。

### N4 · `assets/planner.js`（可执行精力组合）

- **作用**：`plan({serverId,budget,pool,caps})` → `{profit,energyUsed,energyIdle,allocations,bySkill,legacyGreedyProfit}`。
- **验收**：A+B 不含自产 39,696/2,997E；锻造 8,410/910E；保守 A 28,190/2,982E；闲置提示。

### N5 · `scripts/backfill-price-history.mjs`（历史补录）

- **作用**：从 `git log -- assets/data.js` 补 26 个快照，合并 13 个 JSON，去重，写 v2。
- **验收**：30 快照；11-20 10:07 202/202；无重复；旧查询不回归。

### N6 · `scripts/build-audit-data.mjs`（构建期审计摘要）

- **作用**：生成 Web `assets/audit-data.js`、小程序 `shared/audit.json`、小工具 `audit-data.js`。
- **验收**：Web 全量 A/B/C/blockedBy；小程序/小工具只带摘要，包体积可控。

### N7 · `/audit` 数据审计页

- **作用**：天数/节点/覆盖/实价/薄价/示例/缺价/版本切换/硬缺口/纸面陷阱/导出。
- **验收**：只读；能从 /analysis 底部进入；不占顶级导航。

### N8 · `scripts/test-landability.cjs`（回归）

- **作用**：golden dataset + 单测；固定 30 快照 fixture。
- **验收**：A1/A2/A3/A5/A7 的核心数字不漂移；任何阈值调整必须显式更新 fixture。

## 5. 需要调整的现有模块

### 5.1 数据层

#### 5.1.1 `scripts/update-jx3-prices.mjs`（P0，1.5d）

**现状**：

- `fetchQuotes` 已经拿到 `{copper, sample, t}`；
- 但写 `serverPrices[server][item] = gold` 时把 `sample/t` 丢了；
- `serverCoverage` 只有每服 `{updated,filtered,noQuote}`；
- 过滤原因没有分项（样本不足/异常高值/接口缺）。

**调整**：

1. 增加 `data.meta.serverQuoteMeta[serverId][itemId] = {sample, at, source:'auction'}`；
2. 过滤原因写 `filteredReasons: {sampleLow, high, zero}`；
3. `priceSource` 只在主服写 `item.priceSource` 不够；改为 `serverQuoteMeta` 逐服；
4. 不改变 `serverPrices` 结构，避免破坏旧代码；
5. 小程序 `catalog.json` 同步带 `serverQuoteMeta`（可裁剪为 sample/at）。

**验收**：

- 任意有报价物品能读到 `sample` 和 `at`；
